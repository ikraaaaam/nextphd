# Project Context

## Product
NEXTPHD is a personal PhD Research & Opportunity Intelligence System.

It is designed to continuously collect, organize, verify, enrich, and prioritize:
* PhD opportunities;
* research leads;
* research signals;
* professor information;
* university information;
* deadlines;
* funding information;
* application tasks.

The user consumes information primarily through a portal.
The system is NOT intended to be a generic job aggregator.

## Primary Product Principle
HIGH RECALL + HIGH PRECISION + SOURCE TRACEABILITY + LOW DAILY COGNITIVE LOAD

The target daily workflow is approximately 5–10 minutes.

## Four Core Intelligence Objects
1. **Opportunity:** A concrete advertised PhD/research position or admission opportunity.
2. **Research Lead:** A professor/lab with strong research alignment even if no vacancy is currently advertised.
3. **Research Signal:** A potentially meaningful event (publication, grant, etc.).
4. **Action:** Something requiring user attention (verify, save, apply, etc.).

## Context Feeding Protocol
* Layer 1 - Always available: AGENTS.md, docs/00-PROJECT-CONTEXT.md, docs/01-PRODUCT-REQUIREMENTS.md, docs/02-ARCHITECTURE.md, docs/09-PHASE-STATUS.md
* Layer 2 - Task-specific: (e.g., docs/03-DATA-MODEL.md, docs/05-AI-SCORING.md)
* Layer 3 - Current implementation: Inspect files directly relevant to current task.
